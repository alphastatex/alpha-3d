# 🌌 ALPHASTATES — 3D Portfolio

Современное портфолио разработчика с интерактивной 3D-графикой, кастомным курсором, горизонтальным слайдером проектов и звуковым сопровождением.

## 🚀 Демо

🔗 [Открыть сайт](https://alphastatex.github.io/alpha-3d/)

## 💼 Проекты в портфолио

- ☕ **[Ombre Coffee](https://alphastatex.github.io/ombre-coffee/)** — лендинг с CRM и Telegram Mini App.
- 💈 **[Brutal Style](https://alphastatex.github.io/barbershop/)** — бруталистичный лендинг с интеграцией Telegram.
- 🎮 **[Neon Arena](https://alphastatex.github.io/neon-arena/)** — киберспортивный клуб (Vite + Canvas 2D + Web Audio).

## 🛠 Стек технологий

- **Фронтенд:** Vanilla JS (ES-модули), HTML5, CSS3
- **3D-графика:** Three.js (WebGL, Post-processing / UnrealBloomPass)
- **Анимации:** GSAP (ScrollTrigger, Timeline), Lenis (Smooth Scroll)
- **Звук:** Web Audio API (процедурная генерация)
- **Сборка и деплой:** Vite, GitHub Actions (CI/CD)

## ✨ Главные фичи

- **Интерактивная 3D-сфера:** реагирует на курсор, взрывается при клике и скролле, пост-обработка через `UnrealBloom`.
- **Горизонтальный слайдер проектов:** Drag-to-scroll (перетаскивание мышкой), плавная инерция и примагничивание к центру на GSAP. Модальные окна с превью кейсов.
- **Умный редактор кода:** кастомный парсер с подсветкой синтаксиса (как в VS Code) и процедурным звуком механической печати (Web Audio API) с рандомным ритмом и частотой.
- **Кастомный курсор:** инверсионный курсор с магнетизмом на кнопках и изменением состояния при наведении на работы.
- **Плавный скролл:** полная интеграция Lenis с анимациями GSAP ScrollTrigger.
- **Адаптив:** полная перестройка сеток и отключение тяжелых эффектов на мобильных устройствах.
