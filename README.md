# 🌌 ALPHASTATES — 3D Portfolio

Современное портфолио разработчика с интерактивной 3D-графикой, кастомным курсором и плавным скроллом. 

## 🚀 Демо
🔗 [Открыть сайт](https://alphastatex.github.io/alpha-3d/)

## 🛠 Стек технологий
*   **Фронтенд:** Vanilla JS (ES-модули), HTML5, CSS3
*   **3D-графика:** Three.js (WebGL, Post-processing / UnrealBloomPass)
*   **Анимации:** GSAP (ScrollTrigger, Timeline), Lenis (Smooth Scroll)
*   **Сборка:** Vite
*   **Звук:** Web Audio API (процедурная генерация звука печатной машинки)
*   **Деплой:** GitHub Actions (CI/CD)

## ✨ Главные фичи
*   Интерактивная 3D-сфера (реагирует на курсор, взрывается при клике и скролле).
*   Кастомный инверсионный курсор с магнетизмом на кнопках.
*   Эффект печатной машинки в терминале с генерацией звука в реальном времени.
*   Плавная анимация появления контента при скролле.
*   Полный адаптив под мобильные устройства.
